# Расстояние между городами

Статический русскоязычный сервис сравнения способов перемещения между двумя городами.

Варианты: самолёт, поезд, автомобиль, пешком.

Геокодирование: OpenStreetMap Nominatim. Автомобильный и пеший маршруты: маршрутизаторы OpenStreetMap. Поезд — расчётная оценка, которую можно заменить специализированным API.

Проект предназначен для открытия и дальнейшей разработки в GigaCode/GigaIDE и публикации через GitVerse Pages.
