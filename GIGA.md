# GigaCode instructions

Проект: русскоязычный сервис расчёта расстояния между городами.

Цель: сохранять простой адаптивный интерфейс и не ломать расчёты.

Функции:
- два поля «Откуда» и «Куда»;
- геокодирование через OpenStreetMap Nominatim;
- самолёт: расстояние по прямой + ориентировочное время;
- поезд: расчётная оценка, явно помеченная как оценка;
- автомобиль: маршрут OpenStreetMap;
- пешком: маршрут OpenStreetMap;
- мобильная адаптация.

При изменениях сначала проверь JavaScript на синтаксические ошибки и не удаляй предупреждение о том, что железнодорожный маршрут является оценкой.

При дальнейшем развитии желательно добавить специализированный API железнодорожных маршрутов и карту маршрута, но не добавлять секретные ключи в клиентский код.
